# ChatGPT Images 2.0 Prompt Pack For ModernClawMacMulti

## Purpose

Use these prompts with real `ModernClawMacMulti` screenshots to generate stronger visual directions for the app facelift.

These prompts are designed to improve:

- shell polish
- layout rhythm
- typography
- color system
- control styling
- premium feel

## General Rules To Include

Append these rules to most prompts:

- Keep the product as a macOS desktop app.
- Preserve the existing information architecture.
- Do not invent new major features.
- Improve visual hierarchy, polish, and composition.
- Make it feel premium, intentional, local-first, and professional.
- Avoid gimmicky neon AI aesthetics.
- Avoid purple-heavy startup branding.
- Use a refined editorial productivity aesthetic.
- Keep the design implementable in React + Tailwind + Tauri.

## Prompt 1: App Shell Direction

Use this with a screenshot of the full shell:

```text
Redesign this macOS desktop AI workspace UI into a more polished premium product interface. Preserve the same layout structure and core controls, but improve typography, spacing, hierarchy, surfaces, and overall composition. The product should feel like a private local-first AI command workspace: editorial, modern, calm, and highly intentional. Use layered warm neutrals, subtle atmospheric gradients, restrained blue accents, and refined depth. Avoid generic SaaS styling, avoid neon futurism, avoid purple-heavy palettes. Make the sidebar feel like a deliberate navigation rail, the header feel quieter and more integrated, and the central controls feel like premium workspace instruments. Keep the result realistic and implementable in code.
```

## Prompt 2: Chat Screen Facelift

Use this with a chat screenshot:

```text
Polish this local AI chat workspace screen while preserving its real structure and features. Improve the empty-state composition, message area rhythm, type hierarchy, spacing, and composer styling. Make the composer feel like a premium command surface rather than a basic textarea dock. The result should feel elegant, trustworthy, local-first, and desktop-native, with stronger depth, better proportion, cleaner cards, and more intentional control styling. Keep it professional and highly usable.
```

## Prompt 3: Settings Screen Facelift

Use this with a settings screenshot:

```text
Redesign this settings screen into a premium desktop control panel. Keep the same functionality and information, but improve the section structure, visual grouping, card hierarchy, form styling, typography, and spacing. Make the layout feel more deliberate and less like a stack of generic fields. Use a polished editorial productivity aesthetic with warm light surfaces, subtle contrast, elegant dividers, strong labels, and a trustworthy workstation feel.
```

## Prompt 4: Brain Selector And Model Controls

Use this with a screenshot of the header and selectors:

```text
Refine these workspace control capsules for a premium local AI desktop app. Preserve the same brain selector, model selector, and top-bar functionality, but make them feel more cohesive, tactile, and professionally art-directed. Improve proportion, alignment, control hierarchy, icon treatment, and micro-surface styling. The result should feel like high-end desktop productivity software, not a prototype.
```

## Prompt 5: Three Visual Directions

Use this when you want exploration instead of one answer:

```text
Create three distinct redesign directions for this exact app screen while preserving the same underlying product structure. Direction 1 should be calm editorial productivity. Direction 2 should be bold local command workstation. Direction 3 should be warm premium craft intelligence. Each direction should feel polished, product-ready, and realistic to implement in code.
```

## Prompt 6: Tighten, Don’t Reinvent

Use this when the generated concepts drift too far:

```text
Do not redesign the product from scratch. Tighten and elevate what is already here. Keep the same real interface architecture, preserve the product identity as a local-first AI workspace, and focus only on making the existing experience more visually polished, premium, and intentional.
```

## Prompt 7: Extract Design System

Use this after you get an image you like:

```text
Based on this redesigned screen, extract the implied design system: color palette, surface layers, border treatments, corner radii, spacing rhythm, heading scale, body typography, button styling, input styling, and shadow logic. Present it as a concise UI system that can be implemented in code.
```

## Target Screens

Best first screenshots to run through this workflow:

1. full app shell with sidebar and header
2. chat screen with empty state
3. chat screen with active conversation
4. settings page
5. setup or onboarding screen

## Review Questions

Use these after each generated direction:

- Does this still feel like ModernClaw?
- Does it look buildable, or just pretty?
- Is the hierarchy clearer than the current UI?
- Does it feel more premium without becoming flashy?
- Would this help the app feel more trustworthy to a first-time user?

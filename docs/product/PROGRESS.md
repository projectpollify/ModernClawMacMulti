# docs/product/PROGRESS.md (Archived)

This file tracked the `ModernClawBase` split — the strategy of carving out a free open-source base edition from the broader product.

**That split is no longer the direction.** As of 2026-06-01, ModernClaw is being shipped as a single paid macOS product (`ModernClawMacMulti`) with three complexity modes (Simplified / Custom / Complete). See `CLAUDE.md`, `VISION.md`, and `docs/MODERNCLAW_MONETIZATION_PLAN.md` for the current strategy.

The active progress log for the shipping product is [`PROGRESS.md`](../../PROGRESS.md) at the repo root.

This file is preserved for history. Do not act on its task lists or status claims — they describe a product direction that has been retired.
